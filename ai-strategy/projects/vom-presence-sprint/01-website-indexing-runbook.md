**Execution order for the full sprint: see 00-master-runbook.md**

## Evidence Preamble

**Verified Site Status (as of 2026-07-14):**
- Platform: WordPress on Apache + PHP 8.4, behind Varnish reverse proxy cache
- robots.txt: Clean and permissive — only disallows `/wp-admin/`, explicitly allows `admin-ajax.php`
- Sitemap declared in robots.txt: `https://www.visionoutreachmedia.nl/sitemap_index.xml`
- Sitemap structure: 5 child sitemaps (post, page, vom_ai_app, category, vom_app_category) with lastmod dates June–July 2026 — generated by Rank Math SEO plugin
- Homepage meta robots tag: `follow, index, max-snippet:-1, max-video-preview:-1, max-image-preview:large` (no noindex)
- Google index status: `site:visionoutreachmedia.nl` returns zero results → site has never been crawled by Googlebot or is too recent to have been indexed
- Backlink status: No known inbound links identified
- Site purpose: Websites & Media services for churches, ministries, and nonprofits in the Netherlands

**Root cause:** Site is not in Google's index because it has not been submitted to Search Console and Google has no reason to discover it (zero backlinks, brand new or recently created). Varnish caching will not block indexing if cache headers are correct (they typically are by default).

## 1. Google Search Console Setup

### 1.1 Property Type Recommendation

**Use: Domain property** (not URL-prefix)

**Rationale:**
- A domain property covers all protocols (http://, https://) and subdomains (www.*, api.*, etc.) in one property
- For visionoutreachmedia.nl, which is likely a single cohesive site served via www, a domain property is simpler to manage than a URL-prefix property
- You will not need to re-add the property if you ever migrate from HTTP to HTTPS or add subdomains
- Verification is slightly more complex (DNS TXT), but this is a one-time effort

**Alternative:** If you prefer not to touch DNS or lack access to the domain registrar, you can use a URL-prefix property (`https://www.visionoutreachmedia.nl/`) instead; the steps below still work, but you would only cover that specific protocol and path.

### 1.2 Verification Methods (in order of recommendation for this stack)

#### Option A: Rank Math Search Console Integration (RECOMMENDED)

**Prerequisite check — confirm Rank Math is installed:**
- WordPress admin: Plugins > Installed Plugins — look for "Rank Math SEO" (Active).
- No admin access yet? Fetch the homepage or `sitemap_index.xml` and look for "generated by Rank Math" in the sitemap comments. **Already confirmed present on this site** (see Evidence Preamble above — the sitemap's child sitemaps are "generated by Rank Math SEO plugin").
- If Rank Math is absent: any SEO plugin with sitemap + Search Console verification support (e.g., Yoast) works as a substitute for Option A below; otherwise use Option B/C/D (all plugin-independent).

**Why this first:** Rank Math has built-in Google Search Console integration. This avoids manual verification and keeps configuration in WordPress.

**Steps:**

1. Log in to WordPress admin at `https://www.visionoutreachmedia.nl/wp-admin/`
2. Navigate to **Rank Math** > **Search Console**
3. Click **Connect Google Search Console**
4. Authorize Rank Math to access your Google account (you will be redirected to a Google login and permission prompt)
5. Grant Rank Math access to Google Search Console
6. Select or create a new Search Console property:
   - Choose **Domain property** and enter: `visionoutreachmedia.nl`
   - Complete the setup flow
7. Rank Math will automatically inject a verification meta tag into your site's `<head>` (you do not need to manually add it)
8. Google will verify ownership within seconds to a few minutes

**Rollback:** If needed, disconnect via **Rank Math > Search Console > Disconnect** and manually delete any injected meta tags from the site's header.

**Verification check:** Once connected, you should see your site's coverage and performance data in the Rank Math Search Console dashboard.

---

#### Option B: HTML Meta Tag (if Option A fails or you prefer manual control)

**Steps:**

1. In Google Search Console, select **Domain property** > **visionoutreachmedia.nl**
2. Go to **Settings** > **Verification**
3. Select the **HTML Tag** verification method
4. Copy the meta tag (looks like: `<meta name="google-site-verification" content="ABC123...">`)
5. In WordPress admin, install or use an existing plugin to inject this tag:
   - **Method 1 (easiest):** Use Rank Math's **Settings > Titles & Meta** and add the verification meta tag to a custom meta tag field, or
   - **Method 2:** Edit the site's header.php or footer.php (if direct template access) to add the tag before `</head>`, or
   - **Method 3:** Use a lightweight plugin like **Header and Footer Scripts** to inject it
6. Save and publish
7. Return to Google Search Console and click **Verify**
8. Verification should complete within seconds

**Rollback:** Remove the meta tag from the template or plugin field.

---

#### Option C: DNS TXT Record (most reliable for domain property, but requires DNS access)

**Steps:**

1. In Google Search Console, select **Domain property** > **visionoutreachmedia.nl**
2. Go to **Settings** > **Verification**
3. Select the **DNS** verification method
4. Copy the TXT record value (looks like: `google-site-verification=ABC123...`)
5. Log into your domain registrar (e.g., GoDaddy, Namecheap, etc.)
6. Navigate to **DNS Settings** for the domain `visionoutreachmedia.nl`
7. Add a new TXT record:
   - **Name/Host:** `@` (or leave blank, depending on registrar)
   - **Value:** Paste the verification string from Google
   - **TTL:** 3600 (or default)
8. Save and return to Google Search Console
9. Click **Verify**
10. DNS propagation may take a few minutes (5–30 min); refresh the page if verification doesn't succeed immediately

**Rollback:** Delete the TXT record from your DNS provider.

---

#### Option D: HTML File Upload (if you have direct file access)

**Steps:**

1. In Google Search Console, select **Domain property** > **visionoutreachmedia.nl**
2. Go to **Settings** > **Verification**
3. Select the **HTML file** verification method
4. Download the verification file (e.g., `google1234567890abcdef.html`)
5. Upload it to the root of your site via SFTP/FTP or WordPress media:
   - **Via SFTP:** Upload to `/public_html/` or `/var/www/html/` (the web root)
   - **Via WordPress media:** Upload via **Media > Add New**, but ensure it's accessible at `https://www.visionoutreachmedia.nl/google1234567890abcdef.html`
6. Return to Google Search Console and click **Verify**
7. Verification should complete within seconds

**Rollback:** Delete the uploaded file.

---

### 1.3 Recommended Verification Path

1. **Start with Option A (Rank Math)** — it is the fastest and requires no DNS or file upload access.
2. If that fails, use **Option B (HTML meta tag)** as the fallback.
3. Only use DNS or file upload if you encounter issues with the above.

## 2. Sitemap Submission

### 2.1 Submit to Google Search Console

**Prerequisite:** You must have completed verification in Section 1.

**Steps:**

1. In Google Search Console, go to your property: **visionoutreachmedia.nl** (domain property)
2. In the left sidebar, click **Sitemaps**
3. In the **Add a new sitemap** field, enter the sitemap URL (without the protocol):
   - **`sitemap_index.xml`** (Google will auto-prepend `https://www.visionoutreachmedia.nl/`)
   - Or, enter the full URL: `https://www.visionoutreachmedia.nl/sitemap_index.xml`
4. Click **Submit**
5. Google will immediately process the sitemap and display:
   - Status: "Success"
   - Number of URLs discovered in each child sitemap (post, page, vom_ai_app, category, vom_app_category)
6. If status is "Error" or "Couldn't fetch," verify:
   - The sitemap is publicly accessible at `https://www.visionoutreachmedia.nl/sitemap_index.xml` (test in your browser)
   - robots.txt declares it (should already be there per verified facts)
   - No server-level authentication blocks it
   - Varnish cache is not returning a 4xx or 5xx error (check response headers)

**Verification check:** Refresh the Sitemaps page after 5 minutes to see if Google reports any newly discovered URLs.

**Rollback:** Click the sitemap URL and select **Delete sitemap** if you need to remove it (though there is no harm in leaving it submitted).

## 3. URL Inspection & Request Indexing

### 3.1 Why This Step Matters

Submitting the sitemap tells Google the URLs exist, but requesting indexing for key pages accelerates their crawl and index.

### 3.2 Inspect and Request Indexing for Critical Pages

**Step 1: Homepage**

1. In Google Search Console, go to the **URL Inspection** tool (top search bar)
2. Enter: `https://www.visionoutreachmedia.nl/`
3. Click **Inspect**
4. Review the inspection results:
   - **Coverage:** Should show "Inspected - Currently not indexed" (expected on first check)
   - **Rendering:** Verify the page renders correctly and meta robots tag is visible (should show `index, follow`)
   - **Mobile usability:** Should be "No issues"
5. Click **Request Indexing** (red button, top right)
6. Confirm the request; Google will queue the URL for crawling
7. Note the time; you can re-check this URL after 1–2 days to see if indexing has begun

**Step 2: Top 5–10 Content Pages**

Repeat the above for the most important pages:
- **Category/hub pages** (e.g., `/services/`, `/our-work/`, `/blog/`)
- **Flagship posts or case studies** (if any exist)
- **Contact page** (if it contains important info)

**Example URLs to inspect:**
- `https://www.visionoutreachmedia.nl/`
- `https://www.visionoutreachmedia.nl/blog/` (or similar blog/news hub)
- `https://www.visionoutreachmedia.nl/about/`
- `https://www.visionoutreachmedia.nl/services/` (or similar service listing)

**Rollback:** There is no rollback; Google will ignore the request if it is spam or duplicate. Requesting indexing does not harm your site.

## 4. Bing Webmaster Tools & IndexNow

### 4.1 Setup Bing Webmaster Tools

**Why:** Bing powers Microsoft Copilot and Yahoo Search; indexing there is a quick secondary win and often faster than Google.

**Steps:**

1. Go to **https://www.bing.com/webmasters/**
2. Click **Add a site**
3. Enter: `https://www.visionoutreachmedia.nl`
4. Choose a verification method:
   - **Recommended:** Use **Bing's meta tag** method (same as Option B for Google)
   - In Bing, you will receive an HTML meta tag; inject it via Rank Math (same process as Section 1.2, Option B) or direct template edit
   - Bing will verify within seconds
5. Once verified, the site dashboard will open

**Verification check:** After verification, Bing will show basic crawl data.

---

### 4.2 Enable Rank Math's IndexNow Module

**What is IndexNow?** IndexNow is a Microsoft standard for instant indexing. When you publish a new page, it alerts search engines immediately (within minutes), bypassing the wait for a crawl.

**Steps:**

1. In WordPress admin, go to **Rank Math > Settings > Integrations**
2. Locate **IndexNow** (or **Instant Indexing**)
3. Toggle **Enable IndexNow**
4. You will see an option to select your platform:
   - Choose **Bing Webmaster Tools** (the provider)
5. Authorize Rank Math to send IndexNow pings to Bing:
   - Click **Connect** or **Authorize**
   - You will be redirected to Bing to confirm permission
   - Grant access and return to WordPress
6. Save the settings

**Verification check:** After enabling, Rank Math will automatically send IndexNow pings to Bing every time you publish a new post or update an existing one.

**Location in WordPress UI:**
- **Rank Math** (sidebar) > **Settings** > **Integrations** > **IndexNow**

**Rollback:** Go to **Rank Math > Settings > Integrations > IndexNow** and toggle **Disable IndexNow**.

2. Click **Add a sitemap**

## 5. How to Confirm It Worked

### 5.1 Timeline Expectations

- **IndexNow (Bing):** 5 minutes to 1 hour; you should see URLs appear in Bing Webmaster Tools within hours
- **Google (via request indexing):** 1–7 days for the first crawl; 2–4 weeks for full sitemap crawl and indexing
- **Full Google index:** 4–12 weeks, depending on site size and content update frequency
- **Bing full index:** Often faster than Google, typically 1–3 weeks

### 5.2 Check 1: Site Query (Google)

1. Go to **https://www.google.com/search?q=site:visionoutreachmedia.nl**
2. **Initial check (Day 1–2):** Will likely return "About 0 results"
3. **After 1–2 weeks:** Should show results from the homepage and a few top pages
4. **After 4+ weeks:** Should show dozens to hundreds of results (depending on content volume)

### 5.3 Check 2: Google Search Console Coverage Report

1. In Google Search Console, go to **Coverage**
2. You should see a chart showing:
   - **Indexed:** The number of pages successfully indexed (starts at 0, grows over days/weeks)
   - **Discovered - not indexed:** Pages found but not yet indexed
   - **Excluded:** Pages not indexed due to robots.txt, noindex, etc.
3. **Healthy milestone:** After 2–4 weeks, you should have 50%+ of URLs showing as "Indexed"

### 5.4 Check 3: Google Search Console Performance Report

1. In Google Search Console, go to **Performance**
2. After indexing begins (usually 3–7 days), this report will populate with:
   - **Impressions:** How many times VOM appears in search results
   - **Clicks:** How many people clicked the link
   - **CTR (Click-through rate):** Typically 1–3% for a new site
   - **Position:** Average search rank
3. A healthy new site will show a few impressions per day initially, growing to dozens/hundreds per day by week 4

### 5.5 Check 4: Bing Webmaster Tools Index Status

1. In Bing Webmaster Tools, go to **Index status**
2. You should see:
   - **Pages indexed:** Will grow from 0 to hundreds within hours to days
   - **Pages crawled:** Shows Bingbot activity

### 5.6 Manual Crawl Simulation (Optional, Advanced)

If you want to verify the site is crawlable and rendering correctly:

1. Install a tool like **Screaming Frog SEO Spider** (free tier)
2. Configure it to crawl `https://www.visionoutreachmedia.nl` with a limit of 50 URLs
3. Verify:
   - All URLs return HTTP 200 (or 301 redirects to live pages)
   - Meta robots tag is present and does not contain `noindex`
   - Canonical tags are correct
   - No blocking Varnish or WAF rules

## 8. Post-Execution: First 30 Days

### Weekly Milestones

- **Week 1:** GSC shows site verified, sitemap submitted, 1–5 pages showing in "Discovered - not indexed". Bing shows 10–50 pages indexed.
- **Week 2:** GSC shows 10–20 pages indexed. Bing shows 50–200 pages indexed. site: query may show 1–10 results.
- **Week 3–4:** GSC shows 30–50%+ of URLs indexed. Bing shows most or all URLs indexed. site: query shows 20+ results. Performance tab begins showing impressions (1–5 per day).

### If Indexing is Slower Than Expected (No Progress After 4 Weeks)

1. **Check robots.txt:** Verify it is still allowing the homepage and key pages (run `curl https://www.visionoutreachmedia.nl/robots.txt`)
2. **Check meta robots:** Inspect the HTML of a few pages to ensure they do not have `noindex` (use Google's URL Inspection tool)
3. **Check Varnish headers:** Verify cache headers are not returning `X-Robots-Tag: noindex` or similar
4. **Check server logs:** Look for 4xx or 5xx errors when Googlebot visits; contact your host if you see blocking
5. **Resubmit sitemap:** In GSC, click the sitemap and manually request recrawl
6. **Request indexing again:** Use URL Inspection for the homepage; sometimes a second request helps

### KPIs to Track

- **Indexed pages:** Target 50%+ by Week 4
- **Search impressions:** Target 10–50 by Week 4 (via GSC Performance)
- **Google organic clicks:** Target 1–5 by Week 4
- **Bing indexed pages:** Target 80%+ by Week 2
