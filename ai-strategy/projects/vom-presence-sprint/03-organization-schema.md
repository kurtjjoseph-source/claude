### Why Use Rank Math Instead of Raw JSON-LD?

Rank Math automatically generates and maintains Organization JSON-LD from plugin settings. This avoids:
- Manual code injection and maintenance
- Duplicate schema if Rank Math also generates it
- Hard-coded URLs that break if you update the domain

**Rank Math will emit its own Organization schema**, so use the plugin for configuration first, then use the raw JSON-LD above only if Rank Math's output is incomplete or if you need additional fields.

## 3. Footer Social Links: Accessible HTML + Crawler Discovery

### Why Footer Social Links Matter

1. **Crawler Discovery Loop:** Links from your site → social profiles (via `sameAs`), plus links from profiles → your site (via bio/about links), close the discoverability loop for search engines
2. **User Trust:** Visible links to active social profiles build credibility
3. **Accessibility:** Properly labeled, keyboard-navigable links improve accessibility for screen readers

### Recommended HTML Structure

Add this **accessible footer navigation** to your WordPress theme footer (typically `wp-content/themes/[theme-name]/footer.php`):

```html
<nav aria-label="Social media links">
  <ul>
    <li>
      <a href="https://www.instagram.com/visionoutreachmedia" rel="me noopener" target="_blank">
        Instagram
      </a>
    </li>
    <li>
      <a href="https://x.com/visionoutreachmedia" rel="me noopener" target="_blank">
        X (Twitter)
      </a>
    </li>
    <li>
      <a href="https://www.youtube.com/@visionoutreachmedia" rel="me noopener" target="_blank">
        YouTube
      </a>
    </li>
    <li>
      <a href="https://www.facebook.com/visionoutreachmedia" rel="me noopener" target="_blank">
        Facebook
      </a>
    </li>
    <li>
      <a href="https://www.linkedin.com/company/[CORRECT-ID]" rel="me noopener" target="_blank">
        LinkedIn
      </a>
    </li>
  </ul>
</nav>
```

### CSS Styling Example

```css
nav[aria-label="Social media links"] ul {
  list-style: none;
  padding: 0;
  display: flex;
  gap: 1rem;
  flex-wrap: wrap;
}

nav[aria-label="Social media links"] a {
  display: inline-flex;
  align-items: center;
  gap: 0.5rem;
  padding: 0.5rem 1rem;
  background-color: #f0f0f0;
  border-radius: 4px;
  text-decoration: none;
  color: #333;
  font-weight: 500;
  transition: background-color 0.2s ease;
}

nav[aria-label="Social media links"] a:hover,
nav[aria-label="Social media links"] a:focus {
  background-color: #007bff;
  color: white;
  outline: 2px solid #0056b3;
}
```

### HTML Attributes Explained

- **`aria-label="Social media links"`** — Helps screen reader users understand the navigation purpose
- **`rel="me"`** — Signals to crawlers that you endorse this profile (bidirectional link authority)
- **`rel="noopener"`** — Security measure; prevents the linked page from accessing your `window` object
- **`target="_blank"`** — Opens social profiles in a new tab (UX best practice; users stay on your site)
- **`href`** — Must be the verified, canonical URL (e.g., `https://www.instagram.com/visionoutreachmedia`, NOT `instagram.com/visionoutreachmedia`)

---

### How This Closes the Crawler Loop

1. Your site's footer links → social profiles (search engines follow these links)
2. Each social profile's bio/about section links back → your site (e.g., "Visit https://www.visionoutreachmedia.nl")
3. The Organization `sameAs` array in schema confirms the relationship
4. Result: Search engines recognize VOM across multiple properties, boosting domain authority and profile discoverability

## Notes

1. **JSON-LD Validation:** Always test your Organization schema before going live. Malformed JSON or incorrect `sameAs` URLs can be flagged as broken schema by search engines.

2. **rel="me" Authority:** The `rel="me"` attribute signals to crawlers (especially identity aggregators like Google and SEO tools) that you endorse and own these profiles. It's critical for cross-platform authority.

3. **Platform-Specific Requirements:**
   - **Instagram:** Must be public profile with posts visible (private profiles are not indexed)
   - **LinkedIn:** Company page must be public and match your organization
   - **X/Twitter:** Account must be public (protected accounts not indexed)
   - **YouTube:** Channel must be public with videos visible
   - **Facebook:** Page must be published (not in Draft) and audience set to "Everyone"

4. **If Profiles Are Deleted After Publishing:** Update your schema immediately. Dead `sameAs` links hurt SEO; better to have no sameAs entry than a broken one.

5. **Rank Math vs. Raw Schema:** Rank Math is the recommended first-line approach (plugin-maintained, always up-to-date). Use raw JSON-LD only if Rank Math doesn't support the fields you need or if you're adding custom extensions.
