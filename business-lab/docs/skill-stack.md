# Untitled stack

**Stack:** 01 Agent operator · 06 IRL community builder

> Pick one and get dangerous. Pick two and you have leverage. Pick three and you are the person everyone wants on the team, in the room, or building the company.

---

## 01 — Agent operator

Set agents up properly, manage them, run local models.

**First rep:** Build a daily briefing agent for yourself. Three sources. One goal. Two hard rules. Scheduled. With a success test you can actually fail.

**Teaches:** context, retrieval, tool use, permissions, evals  
**Success test:** Did it save ten minutes, catch something you'd have missed, or produce something you actually used?  
**The trap:** Trying to build the all-knowing agent first. Build something small, make it genuinely valuable, schedule it, then grow it.

```
AGENT: daily briefing

SOURCES
  1. ‹calendar›
  2. ‹notes folder›
  3. ‹saved links›

GOAL
  ‹what matters today, decisions waiting, follow-ups owed›

RULES
  1. ‹show sources — not yet accepted›
  2. ‹ask before sending — not yet accepted›

RUNS
  ‹unscheduled›

LOCAL
  ‹not decided›

SUCCESS TEST
  ‹pick one›
  Checked by: ‹how?›

STOP CONDITION
  If it fails the test for five days running, change one thing — not five.
```

## 06 — IRL community builder

Small rooms, one sharp question, a recap that turns them into a network.

**First rep:** Six to eight people around one sharp question. A dinner, a walk, a hike, a breakfast. Then a recap that gives the room a memory.

**Teaches:** curation of people, hosting, ritual, follow-through  
**Success test:** Does anyone ask when the next one is — without you prompting?  
**The trap:** Starting with a big event. And skipping the recap, which is the thing that turns a room into a network.

```
INVITE

  ‹format› — ‹when and where›
  One question: ‹the sharp question›
  Six to eight people who can actually answer it. No panel, no name tags.

GUEST LIST (0)
  ‹add six to eight›

RITUAL
  ‹same time, same people, same promise›

RECAP — within 24 hours
  [ ] The best quotes, attributed
  [ ] The inside jokes
  [ ] The ideas that came up
  [ ] One follow-up: ‹the ask›

The recap is what turns the room into a network.
```

## Two weeks

| When | Skill | What you do |
|---|---|---|
| Days 1–2 | Agent operator | Wire the three sources. Nothing clever — just get them readable. |
| Days 3–4 | Agent operator | Write the goal and the two rules. Run it manually and read the output. |
| Days 5–7 | Agent operator | Schedule it. Start the one-line daily log: used / ignored / why. |
| Week 2 | Agent operator | Move one part local. Grade it against your success test. |
| Days 1–2 | IRL community builder | The question. Then the list of six to eight who can answer it. |
| Days 3–5 | IRL community builder | Invites out. Keep it small on purpose. |
| Week 2 | IRL community builder | Host it. Send the recap within 24 hours. |
| After | IRL community builder | Set the ritual — same time, same kind of people, same promise. |
