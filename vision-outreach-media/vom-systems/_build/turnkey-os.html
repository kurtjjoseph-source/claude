Install the engine

The OS you are looking at is the cockpit. The pipeline itself runs in Claude Code: one skill, five subagents, one deterministic engine.

git clone git@github.com:kurtjjoseph/vom-turnkey.git
cp -R vom-turnkey/orchestrator/agents/*.md   ~/.claude/agents/
mkdir -p ~/.claude/skills/onboard-business
cp -R vom-turnkey/orchestrator/SKILL.md      ~/.claude/skills/onboard-business/
cp -R vom-turnkey/orchestrator/agents        ~/.claude/skills/onboard-business/
python3 vom-turnkey/orchestrator/engine/turnkey.py selftest

Then, in any validated idea folder:

TK="python3 .../orchestrator/engine/turnkey.py"; IDEA="/path/to/Idea Folder"
$TK init "$IDEA"        # scaffold + seed state
$TK status "$IDEA"      # the frontier — always read this first
$TK blueprint "$IDEA" --save   # org type -> functions + WordPress-or-app
