# Summary — Jack Dorsey's Buzz

**One line:** Buzz is an open-source, agentic alternative to Slack (built by Jack Dorsey / Block on the Nostr protocol) where AI agents are first-class teammates you chat with, huddle, and hand real work to — with a swappable model/harness under every agent and your shared chat as the context engine.

## The 8 ideas that matter

1. **Agents are first-class teammates, not integrations.** In Slack agents are bolt-ons; in Buzz they *are* members of your team.
2. **Swappable harness + portable context.** Run Claude Code / Codex / Goose / Open Code under any agent, switch models anytime, and keep all chat context. Kills "model fatigue."
3. **Shared chat = the context foundation.** The core insight: your workspace is your context hub. Everything (agents, humans, apps) draws from one shared context window.
4. **Build & deploy on the fly.** Agents create projects, work in parallel git work-trees, push to repos, deploy live (e.g. "spin up a CRM in Wasp, deploy to Railway"), and send back preview links + screenshots.
5. **Closed context loops.** Wire an app → public API → daily workflow that posts data back into a channel, so agents can analyze it in context (Vinnie's tweet-leaderboard example).
6. **Audio huddles with agents.** Live voice with agents that keep full chat context — closer to the "FaceTime your agents" future.
7. **Openness = ownership.** Built on Nostr (open protocol) → easy integrations, data portability, model choice, shared local compute, and (coming) Bitcoin Lightning micropayments between agents/people.
8. **Pin agents to models + a Chief Agent Officer.** Match each agent to the cheapest-capable model (Fable/Sonnet/etc.) and use a delegator agent to route tasks.

## Verdict
Early preview (alpha/beta) — can be slow, workflows still rough, not for heavy software engineering yet. But the **sweet spot is solopreneurs and small teams (1–10 people, $0–10M rev)** who want one central, context-rich place to brainstorm and ship. Worth getting your hands dirty now.

## Why it matters for the House
The House already runs on exactly this pattern — a swarm of specialized agents (biz-intake/foundation/build/market/operate, the devops-scrum swarm), skills, and a shared context. Buzz is a candidate **operating surface** to run the House's agent team from one workspace, with community channels for Operator's Academy / Church Media Academy / vital., and closed loops feeding Engage AI scores, Stripe sales, and lead data back to the agents. The wizard turns these ideas into a concrete, House-specific setup plan.
