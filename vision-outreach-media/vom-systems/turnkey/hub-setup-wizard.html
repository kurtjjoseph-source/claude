Client Hub — SetupSecrets & provisioning

Start

Turn the client-hub backend on.

The hub runs in local mode until you give it four secrets on its Vercel project. This wizard generates the one you invent (the provision token) and gathers the three you collect (a KV store + a Brevo key), then hands you an exact env block + commands to paste. Everything stays in this browser — nothing is sent anywhere.

Target project: client-hub on Vercel (vom-client-hub.vercel.app). Set these for Production, then redeploy.

1 · Generate

PROVISION_TOKEN

A high-entropy secret you invent — the pipeline sends it with every POST /api/provision to register a business. Anyone without it is refused (the endpoint is fail-closed). Generate one, keep it safe.

—
32 random bytes, base64url. This is the value of PROVISION_TOKEN. The pipeline's turnkey provision-hub gate script references it as $PROVISION_TOKEN — you paste the value when you run the curl.

2 · Gather

KV store — real persistence

Without a shared store, sign-in and saved data reset on every serverless request. Create a KV database (Vercel KV or Upstash Redis — both expose a REST URL + token) and paste the two values here.

Vercel → Storage → Create KV ↗  ·  or Upstash Redis ↗

3 · Gather

Brevo — real magic-link email

Optional but recommended. With a Brevo key the hub actually emails the sign-in link; without it, the link is shown on screen (fine for testing). VOM already uses Brevo for Engage AI, so you likely have a key.

Brevo → SMTP & API → API Keys ↗

4 · Apply

Set them on Vercel, then redeploy.

Saves as client-hub.env.txt (your browser confirms the download). Vercel's Import .env reads the contents — the name/extension doesn't matter. Prefer no file? Use ⧉ Copy .env block and paste it straight into Vercel.

After setting them: redeploy the project (vercel deploy --prod in turnkey/client-hub, or "Redeploy" in the dashboard). Then /api/session reports persistent:true and the hub goes live end-to-end.
These values are secrets. They're kept only in this browser (localStorage) and this page makes no network requests — nothing is transmitted. Clear them when done with Reset below.
